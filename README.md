## 📋 Descripción
Sistema por consola desarrollado en Python que analiza variables 
de configuración de un servidor, evalúa reglas lógicas y genera 
alertas y recomendaciones técnicas automáticas.

# Datos que solicita el sistema
- Porcentaje de uso de CPU
- Porcentaje de uso de RAM
- Espacio libre en disco (GB)
- Cantidad de usuarios conectados
- Cantidad de procesos activos
- Sistema operativo (linux / windows server)
- Estado del firewall (activo / inactivo)
- Tipo de servidor (web / base de datos / archivos)
- Nombre del servidor
- Nombre del administrador responsable
